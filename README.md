# Flatmate-HQ

Household organiser for shared expenses, receipts, chores, shopping, reminders, calendar events, fines and recent activity.

## Run locally

No build step or dependency installation required.

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000.

## Project context

- [Project handover](PROJECT-HANDOVER.md): features, architecture, decisions and known limitations.
- [Changelog](CHANGELOG.md): original development history.

Data is currently saved in each browser. Use the app’s settings to export/import household backups. Keep real backups and receipt files out of this repository.

The original app commits have been preserved alongside this repository’s initial commit. Pushing code to GitHub does not automatically update the live Sites deployment.
